Проверены границы периода включительно, переход года, високосные даты, формат даты YYYY-MM-DD, группировка дата → Company → Ship, независимость компаний с одинаковыми названиями судов, объединение нескольких файлов одной группы, нумерация заново для каждого судна, пустые группы и дни. Также проверены чтение одинаковых дат во вложенных папках, отсутствие/списки/ссылки/ошибки YAML properties, вложенные списки, многострочные пункты, код, комментарии, Unicode и эмодзи, пользовательские статусы чекбоксов, фильтры завершённых задач, конфликты имён и отсутствие перезаписи.

Зависимости зафиксированы точными версиями в `package.json` и `package-lock.json`. В runtime включены `marked` 16.4.2 и `entities` 6.0.1; YAML разбирает публичный `parseYaml` приложения Obsidian. Типы Obsidian 1.8.7 согласованы с peer-зависимостью официального анализатора и используются только при разработке. Vitest обновлён до 5.0.5, тестовый YAML-парсер — до 2.9.1. Транзитивный Moment для инструментов закреплён на исправленной версии 2.31.0 и не входит в main.js. Системный обмен вызывается отдельным нажатием после подготовки текста.

ESLint содержит два узких, прокомментированных исключения: рекомендованный декларативный поиск настроек требует Obsidian 1.13, поэтому сохранён совместимый с 1.5 метод display(); устаревший execCommand разрешён только как явно вызванный резервный способ копирования в старых WebView. Правила безопасности, запрет HTML-инъекций и Node API не отключены.

Независимый Codex Security аудит исходного выпуска 1.1.0 завершён: подтверждённых уязвимостей первого уровня кода не найдено. Замечания профилактического усиления (состав исходного ZIP, скрытые подпапки, повторная валидация дат при записи) исправлены в 1.1.1 и покрыты проверками. Новая версия не выдаётся за отдельный повторный независимый аудит.

Тестовый запускатель разрешает jsdom локально и отключает необязательную автоматическую установку пакетов Vitest. Это обходит ошибку Vitest при поиске пакетов через некорректный `package.json` в посторонней родительской папке. Посторонние файлы компьютера не изменялись.

## Границы проверки

Запуск самого плагина **в установленном Obsidian и на физическом Android не подтверждён**. На компьютере обнаружен Obsidian 1.14.5, создан отдельный тестовый vault. Попытка GUI-проверки не дала надёжного управления окном (ошибка coordinate input geometry is unavailable и несоответствие снимка выбранному окну), поэтому это не считается успешным запуском. Рабочий vault не использовался для установки плагина. UI проверен в jsdom с имитацией Obsidian; внешний вид в реальной теме и экранной клавиатуре остаётся ручной проверкой. Минимальная версия 1.5.7 проверена дополнительной компиляцией с её опубликованными типами API; отдельный запуск на этой версии не выполнялся.

Нативный Web Share может отсутствовать в Android WebView. Этот случай покрыт тестами: остаются TXT в vault, копирование и выделение текста для ручного действия. Доступность именно системного меню обмена на каждом устройстве не обещается.

Для проверки на телефоне используйте установочную инструкцию и заметки из `examples/`, затем сравните TXT с `examples/expected.txt`, проверьте копирование и кнопку «Поделиться».

Архивы сопровождаются SHA-256 в `SHA256SUMS.txt`; результаты проверки ZIP и совпадения содержимого находятся в отдельном `archive-validation.json` рядом с архивами выпуска.
