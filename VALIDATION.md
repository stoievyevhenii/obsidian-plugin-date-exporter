# Проверка текущей сборки 1.1.2

Дата: 26 октября 2026 года.

Изменён формат отчёта: каждый файл выводится отдельным Markdown-блоком со строкой даты == **YYYY-MM-DD** ==, всеми YAML properties в формате «ключ - значение», пустой строкой и выбранными исходными строками. Группировка по Company/Ship и добавление нумерации удалены. Исходные маркеры, номера, чекбоксы, отступы и продолжения строк сохраняются. Счётчик результата показывает число включённых строк тела.

## Проверки

- Автопериод: 1–7 число — весь предыдущий месяц, с 8-го — весь текущий; проверены январь/декабрь, февраль, високосные годы, повторное открытие и ручное изменение дат. Используется местная дата устройства.
- Свойства проверены через разбор и отображение Markdown: отдельные строки «ключ - значение», переносы строк, отсутствие таблицы и активного HTML в свойствах.
- npm run verify: официальный ESLint, тесты, строгая проверка TypeScript, сборка и проверки публикации.
- 147 тестов в 11 файлах: даты и пути, извлечение Markdown и исходных строк, все properties и типы значений, отдельные блоки файлов одной даты, примеры Markdown, имитация Vault API, UI и копирование/обмен, состав архива.
- Сборка для браузера: единственный внешний модуль obsidian, isDesktopOnly: false; Node API и Node globals в runtime отсутствуют.
- Итоговый CommonJS проверяется импортом, onload(), регистрацией команды и onunload() с имитацией публичного API Obsidian.
- Файлы примеров сравниваются с отчётом точно, включая маркеры, строку даты и отсутствие отдельного разделителя.
- Установочный ZIP содержит собранный main.js; исходный ZIP исключает локальные настройки, .env, node_modules и сгенерированный runtime.

## Границы проверки

Тесты UI выполняются в jsdom с имитацией Obsidian. Запуск этой сборки в установленном Obsidian и на физическом Android не подтверждён. Минимальная версия приложения 1.5.7 сохранена; отдельный запуск на ней не выполнялся. Доступность Web Share зависит от Android WebView; сохранение MD, копирование и ручное выделение доступны как резервные действия.

Ранее выполненные независимый аудит 1.1.0 и проверка зависимостей 24 октября не выдаются за новый аудит текущей сборки.
