Export daily Markdown lists to one TXT report grouped by date, Company and Ship. Supports desktop and Android, configurable note folders/date filenames, inclusive date ranges, task filters and explicit copy/share actions.

This release prepares Community publication, improves path handling and source-archive selection, updates development dependencies and includes the full license notices in the runtime bundle. There are no network requests, telemetry, paid features or account requirements.

Install the attached `main.js`, `manifest.json` and `styles.css` under `<vault>/<configDir>/plugins/daily-notes-txt-export/`, or use the installation ZIP. Native sharing depends on platform Web Share support; clipboard and manual selection fallbacks remain available.
